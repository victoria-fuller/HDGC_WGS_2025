# Pipeline description
## Short variant pipeline
Processes output from nf/core-sarek GATK Haplotypecaller in gVCF mode to filtered VCF file

## Structural variant pipeline
Processes output from nf-core/sarek Manta to joint germline filtered VCF file

## Copy number variant pipeline
Processes output from nf-core/sarek cnvkit to joint germline filtered VCF file
